# Directional analysis scripts

Cleaned scripts:

- `reproduce_directional_analysis_1.py`: reproduces Table S4 and Table S5 from the saved Directional Analysis 1 projection-correlation and GSEA workbooks.
- `reproduce_directional_analysis_2.py`: reproduces Table S6 and Table S7 from the saved Directional Analysis 2 projection-correlation and GSEA workbook.

Related figure script:

- `../figures/plot_directional_gene_dotplots.py`: plots the Figure 5C-D and Figure S4C-D directional gene dotplots from regenerated Table S4/Table S6 workbooks and the all-cell AnnData object.
- `../figures/plot_directional_gsea_panel.py`: plots the Figure 5E and Figure S4E GSEA NES panels from regenerated Table S5/Table S7 workbooks.

The interactive SCIViewer selection step is documented in:

- `../../notebooks/reproduce_directional_analysis_1.ipynb`
- `../../notebooks/reproduce_directional_analysis_2.ipynb`
